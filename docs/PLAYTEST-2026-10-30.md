# Playtest record — By Heart v1.0.0 (2026-10-30)

Automated playtest of record for the sandbox build (the UE 5.8 /
seahawk session on primo is the scheduled follow-up, see
BREAKAGE-LOG).

## Method

- `node tools/playtest.mjs`: the shipped wasm core in demo mode keeps
  each sitting. Pass = victory with zero failed orders and the
  flawless grade (the demo answers on the beat, arms plug orders
  before answering them).
- Native runner (`build/test_core`): 380 checks over the identical
  core translation unit — validation (teach/order flow, ladder
  recovery, plug arming, beat detection, demo completion) and
  adversarial (three-rung failure without lockout, exactly-once
  culmination under replay, near-miss decoy rejection, determinism,
  draw-list bounds on every screen).
- `node tools/settings-check.mjs`: settings + record bridges
  round-trip with clamps; settings reachable from boot, ungated.
- `node tools/perf.mjs`: step budget.
- D-221 visual spot check: frames extracted from the final preview
  MP4s at viewing size and inspected — SHOULD: Piper readable at a
  glance (twin-bun silhouette), the command huge, the window bar
  legible, captions inside the frame. PASS after the raster-advance
  audit fixes (breakage B-3); audit CLEAN on all screens.
